== init
Command: init

Scaffold a sqlode.yaml plus starter db/schema.sql and db/query.sql.

Examples:
sqlode init
sqlode init --output=./config/sqlode.yaml
sqlode init --engine=sqlite --runtime=native
sqlode init --engine=mysql

USAGE:
    sqlode init [ ARGS ] [ --engine=<STRING> --output=<STRING>
        --runtime=<STRING> ]

FLAGS:
    --engine=<STRING>     Target engine: postgresql | sqlite | mysql (default:
                          postgresql)

    --help                Print help information

    --output=<STRING>     Output path for generated config (default:
                          ./sqlode.yaml)

    --runtime=<STRING>    Generated runtime: raw | native (default: raw)
== generate
Command: generate

Parse SQL schema and queries, emit Gleam code.

Without --config, generate auto-discovers sqlode.yaml, sqlode.yml, sqlc.yaml,
sqlc.yml, or sqlc.json in the current directory and fails if more than one
candidate exists.

Examples:
sqlode generate
sqlode generate --config=./custom.yaml

USAGE:
    sqlode generate [ ARGS ] [ --config=<STRING> ]

FLAGS:
    --config=<STRING>     Path to config file. Default: auto-discover
                          sqlode.yaml, sqlode.yml, sqlc.yaml, sqlc.yml, or
                          sqlc.json in the current directory.

    --help                Print help information
== verify
Command: verify

Run static verification on the project without writing files.

Loads the config, parses every schema and query the generator would use, and
runs the full analyser pass. Any query-analysis error, schema warning under
strict_views, or policy violation (for example `query_parameter_limit`) is
collected into a single report.

With --check-generated, verify also renders what generate would write, formats
it with gleam format, and reports each generated file that differs from it or is
missing. Use it in CI after the generated files are committed.

The command exits non-zero when at least one finding is reported — suitable for
CI gates before the generation step runs.

Examples:
sqlode verify
sqlode verify --config=./custom.yaml
sqlode verify --check-generated

USAGE:
    sqlode verify [ ARGS ] [ --check-generated=<BOOL> --config=<STRING> ]

FLAGS:
    --check-generated=<BOOL>  Also fail when a generated file differs from what
                              generate would write, or is missing.

    --config=<STRING>         Path to config file. Default: auto-discover
                              sqlode.yaml, sqlode.yml, sqlc.yaml, sqlc.yml, or
                              sqlc.json in the current directory.

    --help                    Print help information
